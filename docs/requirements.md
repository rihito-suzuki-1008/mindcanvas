# 1. 要件定義

関連: [README](README.md) ・ [architecture.md](architecture.md)

## 1.1 目的・スコープ

ブレインストーミングで出したアイデアを、**最初は自由に置き → 後で構造化する**までを一気通貫で支援する個人向け図解ツール。XMind の階層構造編集と FigJam の自由配置キャンバスを 1 つのアプリで両立する。

| 区分 | 内容 |
|---|---|
| 対象ユーザー | 個人（単独利用）。リアルタイム共同編集は対象外。 |
| 主ユースケース | ブレスト整理、構成図、簡易フロー。 |
| プラットフォーム | GAS スタンドアロン Web アプリ。モダンブラウザ（Chrome 等）。 |

### スコープ外（v1 では実装しない）
- リアルタイム共同編集・コメント・権限管理
- AI 生成（テキスト→マップ等）
- 画像/添付ファイルの挿入
- ノードの色・タグ・アイコン分類
- テンプレート機能、アウトライン表示モード、ガント等のプロジェクト管理

## 1.2 機能要件 (FR)

### FR-1 プロジェクト管理
| ID | 要件 |
|---|---|
| FR-1.1 | ホーム画面でプロジェクトを一覧表示（更新日時降順、サムネ・モードバッジ付き）。 |
| FR-1.2 | 新規作成時に **ツリー型 / フリーフォーム** を選択。作成後の変更は不可。 |
| FR-1.3 | プロジェクトの複製・削除（削除は確認ダイアログ）。 |
| FR-1.4 | プロジェクト名の編集（エディタ上部で随時編集）。 |

### FR-2 シート
| ID | 要件 |
|---|---|
| FR-2.1 | 1 プロジェクトに複数シート（タブ）を持てる。 |
| FR-2.2 | シートの追加・切替・リネーム（タブをダブルクリック）・削除（最低 1 枚は残す）。 |
| FR-2.3 | シートごとに独立した内容とビューポートを保持。 |

### FR-3 ノード
| ID | 要件 |
|---|---|
| FR-3.1 | 形状は角丸四角のみ。幅は可変（グリップでリサイズ）、高さは内容に追従。 |
| FR-3.2 | テキストは **Markdown** 対応：`#`/`##`/`###` 見出し、`**太字**`、`- ` 箇条書き、` ``` ` コードブロック、インラインコード。 |
| FR-3.3 | サブメモ欄（プレーンテキスト、点線で区切り表示）。 |
| FR-3.4 | 作成：フリーフォームはキャンバスのダブルクリック or ノードツール。ツリーは `Tab`/`Enter`。 |
| FR-3.5 | 編集：ダブルクリック / `F2` / `Enter`(選択中) で textarea 編集。`Esc` で取消、`Ctrl+Enter` で確定。 |
| FR-3.6 | 移動（ドラッグ）・リサイズ・削除。 |

### FR-4 接続（エッジ）
| ID | 要件 |
|---|---|
| FR-4.1 | ノード境界のハンドル（上下左右）をドラッグして接続を作成（Figma/Miro 方式）。 |
| FR-4.2 | 接続先が無い空き場所にドロップすると、新規ノードを生成して接続。 |
| FR-4.3 | 4 方向の取り回し + 遠距離向けカーブ（`kind: 'curve'`）。終端に矢印。 |
| FR-4.4 | ラベル付与（ダブルクリック）。選択して削除。 |

### FR-5 ツリーモード
| ID | 要件 |
|---|---|
| FR-5.1 | `parentId` による階層を **右展開ロジックツリー** で自動レイアウト（ルート左→子右、垂直中央揃え）。 |
| FR-5.2 | `Tab`=子追加 / `Enter`=兄弟追加。追加後は即編集状態。 |
| FR-5.3 | 折りたたみ/展開（トグルボタン、折りたたみ時は子数バッジ）。 |
| FR-5.4 | 親子は **枝（branch）線** で自動接続表示。 |
| FR-5.5 | ノードを他ノード上にドロップで再ペアレント。兄弟の並びはドロップ位置の Y で決定。 |

### FR-6 キャンバス
| ID | 要件 |
|---|---|
| FR-6.1 | 無限キャンバス。 |
| FR-6.2 | パン（`Space`+ドラッグ / 中ボタン / ホイール）、ズーム（`Ctrl`+ホイール=カーソル基準、ボタン）。 |
| FR-6.3 | グリッド表示の ON/OFF、グリッドスナップの ON/OFF。 |
| FR-6.4 | ミニマップ（全体俯瞰 + ビューポート矩形 + クリック/ドラッグで移動）。 |
| FR-6.5 | 全体表示（fit）。 |

### FR-7 編集支援
| ID | 要件 |
|---|---|
| FR-7.1 | 単一選択・複数選択（`Shift`+クリック / マーキー矩形）。 |
| FR-7.2 | 整列（左・右・水平中央・上・下・垂直中央）・分配（水平・垂直、3 個以上）。 |
| FR-7.3 | グループ化 / 解除（グループ内 1 つ選択で全体選択・一括移動）。 |
| FR-7.4 | セクション（矩形ドロー作成、内包ノードと一緒に移動、リサイズ、タイトル編集）。 |
| FR-7.5 | コピー / カット / ペースト（グループ・内部エッジも複製）。 |
| FR-7.6 | Undo / Redo（上限 100 ステップ）。 |
| FR-7.7 | ボード全体検索（全シート横断、ハイライト、前後ジャンプ）。 |

### FR-8 保存
| ID | 要件 |
|---|---|
| FR-8.1 | 全変更を localStorage に自動保存（デバウンス）。 |
| FR-8.2 | Google Drive へ自動バックアップ同期（durable store）。 |
| FR-8.3 | 起動時、localStorage と Drive の更新日時を比較し新しい方を採用。 |
| FR-8.4 | 同期状態をUI表示（保存中 / 同期済み / ローカル保存 / 同期失敗）。 |

### FR-9 エクスポート
| ID | 要件 |
|---|---|
| FR-9.1 | PNG（現在シートの全体像、高解像度）。 |
| FR-9.2 | PDF（同上を 1 ページに）。 |
| FR-9.3 | Markdown（プロジェクト全シート。ツリーはネスト、フリーは一覧+接続）。 |
| FR-9.4 | Mermaid（現在シートを `flowchart LR`）。 |

## 1.3 非機能要件 (NFR)

| ID | 要件 |
|---|---|
| NFR-1 操作性 | ドラッグ&ドロップ中心、主要操作にキーボードショートカット。 |
| NFR-2 応答性 | localStorage 即時保存で体感ラグなし。Drive 同期はバックグラウンド（デバウンス）。 |
| NFR-3 堅牢性 | GAS サンドボックス iframe の origin 変動による localStorage 消失に備え Drive を durable store とする。 |
| NFR-4 セキュリティ | Markdown は `DOMPurify` でサニタイズ。Drive スコープは `drive.file`（アプリ作成ファイルのみ）。 |
| NFR-5 権限 | Web アプリは `executeAs: USER_DEPLOYING` / `access: MYSELF`（個人利用）。 |
| NFR-6 保守性 | 機能ごとに JS モジュール分割。`include()` で単一 HTML にインライン化。 |
