# 4. UI・操作・ショートカット

関連: [requirements.md](requirements.md) ・ [modules-api.md](modules-api.md)

## 4.1 画面構成

### ホーム画面 (`#home`)
- ヘッダー：SVG ブランドマーク付きの「MindCanvas」/「新規プロジェクト」ボタン。
- プロジェクトカード一覧（更新日時降順）：SVGサムネ（ツリー / フリー）・名前・更新日時・モードバッジ・[開く][複製][削除]。カードのダブルクリックでも開く。
- 空状態メッセージ。

### 新規プロジェクトモーダル
- プロジェクト名入力 + モード選択（ツリー型 / フリーフォーム）。「作成後にモードは変更できません」。

### エディタ画面 (`#editor`)
```
┌ topbar: [ホーム] [プロジェクト名] [シートタブ…] [シート追加] ……… [同期状態] [検索] [エクスポート] ┐
├ 左 toolbar(縦): 選択 / ノード / セクション | Undo / Redo | グリッド / スナップ / 全体表示
├ align-bar(上中央, 2個以上選択時): 左/中央/右/上/中/下 | 水平分配/垂直分配 | グループ/解除
│
│           [ #stage : 無限キャンバス ]
│
├ zoom-ctl(右下): [ズームアウト] [zoom%] [ズームイン]
├ minimap(右下)
└ search-box(上中央, Ctrl+F): [入力] [n/m] [前へ][次へ][閉じる]
```

## 4.2 ツール（左ツールバー）

| 表示 | ツール | キー | 動作 |

| SVGアイコン | グリッド表示切替 | ― | アクティブ時ハイライト |

左ツールバーの各ボタンは、hover / keyboard focus 時にツール名と主要ショートカットのヒントを表示する。

## 4.3 マウス操作

<!-- 2026-06-10 / #2 follow-up: ツリー型の空白ドラッグ=パン案は、範囲選択を妨げるため取り下げ。空白ドラッグは従来通りマーキー選択。#4 follow-up: フリーフォームの Option/Alt+ノードドラッグ複製は、元ノードから複製ノードへ矢印接続する。 -->

| 対象 | 操作 | 結果 |
|---|---|---|
| 空キャンバス | ドラッグ（選択ツール） | マーキー選択 |
| 空キャンバス | クリック | 選択解除 |
| 空キャンバス | ダブルクリック | ノード作成（その場で編集） |
| 空キャンバス | `Space`+ドラッグ / 中ボタン | パン |
| キャンバス | ホイール | パン |
| キャンバス | `Ctrl/⌘`+ホイール | カーソル基準ズーム |
| ノード | ドラッグ | 移動（選択中の全ノード／ツリーは部分木ごと） |
| ノード | `Option/Alt`+ドラッグ（フリーフォーム） | ノードを複製し、元ノードから複製ノードへ矢印接続。複製ノードのみを移動・選択 |
| ノード | クリック / `Shift`+クリック | 選択 / 追加・トグル選択 |
| ノード | ダブルクリック | テキスト編集 |
| ノード メモ | ダブルクリック | メモ編集 |
| 接続ハンドル(上下左右) | ドラッグ | 接続作成（空きにドロップで新ノード生成） |
| リサイズハンドル（フリーフォーム） | 上下左右・四隅をドラッグ | 最小サイズを保ちながら縦幅/横幅/斜め方向にリサイズ |
| リサイズグリップ（ツリー） | ドラッグ | 幅リサイズ |
| 折りたたみトグル | クリック | 子の折りたたみ/展開（ツリー） |
| エッジ線 | クリック / ダブルクリック | 選択 / ラベル編集 |
| セクション本体の空き領域 | ドラッグ | 移動（内包ノードごと） |
| セクション タイトル | ドラッグ / ダブルクリック | 移動（内包ノードごと） / 名前編集 |
| ミニマップ | クリック・ドラッグ | 表示位置移動 |

## 4.4 キーボードショートカット

> 編集中（textarea/input にフォーカス）はグローバルショートカットを抑止し、エディタ側のキー処理を優先する。

### グローバル（エディタ画面）
| キー | 動作 |
|---|---|
| `Space`（押下中） | パンモード |
| `Ctrl/⌘ + Z` | Undo |
| `Ctrl/⌘ + Shift + Z` / `Ctrl/⌘ + Y` | Redo |
| `Ctrl/⌘ + A` | 全ノード選択 |
| `Ctrl/⌘ + F` | 検索を開く |
| `Ctrl/⌘ + G` / `Ctrl/⌘ + Shift + G` | グループ化 / 解除 |
| `Ctrl/⌘ + C` / `X` / `V` | コピー / カット / ペースト |
| `Ctrl/⌘ + =`(`+`) / `-` | ズームイン / アウト |
| `Ctrl/⌘ + 0` | ズーム 100% |
| `Delete` / `Backspace` | 選択中の要素を削除 |
| `Shift + 1` | 全体表示 (fit) |
| `V` / `N` / `S` | 選択 / ノード / セクション ツール |
| `↑ ↓ ← →` | 選択ノードを 20px 移動（`Shift`+矢印 = 1px） |
| `Esc` | 選択解除・メニューを閉じる |

### 選択が単一ノードのとき
| キー | ツリー | フリーフォーム |
|---|---|---|
| `Tab` | 子ノード追加 | （なし） |
| `Enter` | 兄弟ノード追加 | テキスト編集開始 |
| `F2` | テキスト編集開始 | テキスト編集開始 |

### テキスト編集中（textarea）
| キー | 動作 |
|---|---|
| `Esc` | 取消（元の内容に戻して確定終了） |
| `Ctrl/⌘ + Enter` | 確定 |
| `Enter`（ツリー・本文） | 確定して兄弟ノード追加 |
| `Tab`（ツリー・本文） | 確定して子ノード追加 |
| `Shift + Enter`（ツリー） | 改行 |
| `Enter`（フリーフォーム） | 改行 |

## 4.5 同期ステータス表示

| 表示 | 状態 |

| `✓ ローカル保存` | Drive 未接続環境（localStorage のみ） |
| `⚠ 同期失敗` | Drive 同期エラー |
