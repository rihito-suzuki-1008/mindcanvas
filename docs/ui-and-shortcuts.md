# 4. UI・操作・ショートカット

関連: [requirements.md](requirements.md) ・ [modules-api.md](modules-api.md)

## 4.1 画面構成

### ホーム画面 (`#home`)
- ヘッダー：ブランド「◆ MindCanvas」/「＋ 新規プロジェクト」ボタン。
- プロジェクトカード一覧（更新日時降順）：サムネ（🌳ツリー / 🗺️フリー）・名前・更新日時・モードバッジ・[開く][複製][削除]。カードのダブルクリックでも開く。
- 空状態メッセージ。

### 新規プロジェクトモーダル
- プロジェクト名入力 + モード選択（ツリー型 / フリーフォーム）。「作成後にモードは変更できません」。

### エディタ画面 (`#editor`)
```
┌ topbar: [←戻る] [プロジェクト名] [シートタブ…] [＋] ……… [同期状態] [🔍] [エクスポート▾] ┐
├ 左 toolbar(縦): 選択 / ノード / セクション | Undo / Redo | グリッド / スナップ / 全体表示
├ align-bar(上中央, 2個以上選択時): 左/中央/右/上/中/下 | 水平分配/垂直分配 | グループ/解除
│
│           [ #stage : 無限キャンバス ]
│
├ zoom-ctl(右下): − [zoom%] ＋
├ minimap(右下)
└ search-box(上中央, Ctrl+F): [入力] [n/m] [↑][↓][✕]
```

## 4.2 ツール（左ツールバー）

| アイコン | ツール | キー | 動作 |
|---|---|---|---|
| ▱ | 選択 (select) | `V` | クリック選択・マーキー・移動 |
| ▭ | ノード (node) | `N` | キャンバスをクリックでノード作成（作成後 select に戻る） |
| ⬚ | セクション (section) | `S` | ドラッグで矩形を描いてセクション作成 |
| ↶ / ↷ | Undo / Redo | ― | 履歴 |
| # | グリッド表示切替 | ― | アクティブ時ハイライト |
| ⊞ | スナップ切替 | ― | アクティブ時ハイライト |
| ⤢ | 全体表示 (fit) | `Shift+1` | 全要素が収まるよう調整 |

## 4.4 キーボードショートカット

> 編集中（textarea/input にフォーカス）はグローバルショートカットを抑止し、エディタ側のキー処理を優先する。

### グローバル（エディタ画面）
| キー | 動作 |
|---|---|
| `Space`（押下中） | パンモード |
| `Ctrl/⌘ + Z` | Undo |
| `Ctrl/⌘ + Shift + Z` / `Ctrl/⌘ + Y` | Redo |
| `Ctrl/⌘ + A` | 全ノード選択 |
| `Ctrl/⌘ + F` | 検索を開く |
| `Ctrl/⌘ + G` / `Ctrl/⌘ + Shift + G` | グループ化 / 解除 |
| `Ctrl/⌘ + C` / `X` / `V` | コピー / カット / ペースト |
| `Ctrl/⌘ + =`(`+`) / `-` | ズームイン / アウト |
| `Ctrl/⌘ + 0` | ズーム 100% |
| `Delete` / `Backspace` | 選択中の要素を削除 |
| `Shift + 1` | 全体表示 (fit) |
| `V` / `N` / `S` | 選択 / ノード / セクション ツール |
| `↑ ↓ ← →` | 選択ノードを 20px 移動（`Shift`+矢印 = 1px） |
| `Esc` | 選択解除・メニューを閉じる |

### 選択が単一ノードのとき
| キー | ツリー | フリーフォーム |
|---|---|---|
| `Tab` | 子ノード追加 | （なし） |
| `Enter` | 兄弟ノード追加 | テキスト編集開始 |
| `F2` | テキスト編集開始 | テキスト編集開始 |

### テキスト編集中（textarea）
| キー | 動作 |
|---|---|
| `Esc` | 取消（元の内容に戻して確定終了） |
| `Ctrl/⌘ + Enter` | 確定 |
| `Enter`（ツリー・本文） | 確定して兄弟ノード追加 |
| `Tab`（ツリー・本文） | 確定して子ノード追加 |
| `Shift + Enter`（ツリー） | 改行 |
| `Enter`（フリーフォーム） | 改行 |

## 4.5 同期ステータス表示

| 表示 | 状態 |
|---|---|
| `保存中…` | 変更を保存/同期処理中 |
| `✓ 同期済み` | Drive まで同期完了 |
| `✓ ローカル保存` | Drive 未接続環境（localStorage のみ） |
